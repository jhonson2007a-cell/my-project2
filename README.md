# JARVIS - AI Voice Assistant

JARVIS is a simple Python-based AI Voice Assistant that listens to voice commands and performs different tasks.

##  Features

-  Voice Command
-  Voice Response
-  Open Google
-  Open YouTube
- Tell Current Time
-  Search Information
-  Exit using Voice Command

##  Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- Wikipedia
- Web Browser
- Datetime
